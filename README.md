# 하루책 시연 (녹화판) · HaruBook demo · HaruBook 示範

학생별 맞춤 주간 교재를 가입부터 배송·수업 확인까지 15단계로 따라가는 나레이션 시연입니다. 나레이션은 한국어·English·繁體中文.
